# Mesta

Mesta gives businesses one API for cross-border payments over local bank rails and stablecoins. Use it to collect funds in named virtual accounts, get quotes and send payouts.

## Build an integration

Start with the [API guide](https://docs.mesta.xyz/docs/getting-started), then choose the [TypeScript SDK](https://github.com/mestafi/mesta-typescript) or the [Python SDK](https://github.com/mestafi/mesta-python). The guide covers three payment flows, from stablecoin to fiat, fiat to stablecoin and fiat to fiat.

To look up an endpoint from your editor, connect your coding assistant to the [docs MCP server](https://docs.mesta.xyz/mcp). Reading the reference requires no key. With sandbox credentials, your assistant can also run requests against the staging API. See the [connection instructions](https://docs.mesta.xyz/docs/ai-coding-tools).

The [developer MCP](https://mcp.sandbox.mesta.xyz/developer) provides sandbox tools.
